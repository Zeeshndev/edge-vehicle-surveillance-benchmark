# Contributing to Edge Vehicle Surveillance Benchmark

We welcome contributions, bug reports, and enhancements to this benchmarking suite.

## How to Contribute
1. **Issues:** For bugs, missing dependencies, or delegate compatibility errors, please open an issue in the tracker.
2. **Pull Requests:** 
   - Fork the repository and create a feature branch (`git checkout -b feature/new-eval-metric`).
   - Ensure all pytest unit tests pass before submitting (`pytest tests/`).
   - Maintain clean, descriptive commit messages.
3. **License:** By contributing, you agree that your contributions will be licensed under the project's MIT License.
